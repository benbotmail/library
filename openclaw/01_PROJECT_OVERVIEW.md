# OpenClaw Project Overview

## What is OpenClaw?

OpenClaw is a **personal AI assistant framework** that provides unified access to multiple messaging platforms and AI models through a single gateway interface. It enables developers and power users to build sophisticated automation and conversational AI applications.

## Core Philosophy

> **"EXFOLIATE! EXFOLIATE!"** - OpenClaw aggressively removes friction between you and your AI capabilities.

## Key Characteristics

### 🎯 Unified Messaging Gateway
- **Single Gateway** manages all messaging channels (WhatsApp, Telegram, Slack, Discord, Signal, iMessage, WebChat)
- **WebSocket-based** architecture for real-time communication
- **Channel-agnostic** core routing system

### 🤝 Multi-Model Support
- **OpenAI Code subscription** (OAuth)
- **Anthropic** (API key/setup token)
- **MiniMax, GLM, Ollama, Moonshot, AI Gateway**
- **Extensible** model provider architecture

### 🛠️ Rich Tool System
- **Modular tool profiles** (minimal, coding, messaging, full)
- **Sandboxed execution** with configurable security policies
- **Agent workspace** system with persistent memory
- **Background task** management with persistence
